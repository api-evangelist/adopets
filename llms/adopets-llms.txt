# Adopets

> Adopets is an Adoption Management System (AMS) for animal shelters and rescues that streamlines the adoption process end to end — applications, team collaboration, digital kennel cards, secure payment processing (adoption fees, licenses, products, donations), reporting, and post-adoption communication. Its External API lets partner systems connect staff users and create/manage adoption payment requests and refunds.

This llms.txt was generated by API Evangelist from the Adopets public developer surface and the artifacts in this repository.

## API

- [Adopets External API (OpenAPI, derived)](https://raw.githubusercontent.com/api-evangelist/adopets/refs/heads/main/openapi/adopets-external-openapi.yml): Organization external integration API — system-auth connect/disconnect, payment-request create/get/cancel/change, payment-transaction get/refund. POST + JSON; x-api-key + JWT session bearer.
